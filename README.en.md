### &nbsp;&nbsp;&nbsp;› whoami

Cybersecurity engineering student at CESI Nancy. I enjoy understanding how systems work, and above all how they can be compromised. My goal: become a penetration tester and help organizations find their weaknesses before they get exploited.

🎯 Looking for a 12-week internship starting January 4, 2027, in offensive security (pentesting, auditing) or systems security.

### &nbsp;&nbsp;&nbsp;› right now

**`Penetration Tester path`: Hack The Box Academy**
Full methodology of a penetration test: reconnaissance, enumeration, vulnerability assessment, exploitation, post-exploitation. Every concept is [documented in a knowledge base](https://github.com/mg-root/pentest-hackthebox) -> understanding *why* a technique works, not just memorizing the command.

**`Homelab`**
A home lab I use as an experimentation ground: Docker containers behind a reverse proxy, and several self-hosted services -> WireGuard for encrypted and segmented remote access, AdGuard for DNS filtering, a Samba file share, n8n to automate my workflows, plus various services depending on my projects.

> I also deploy vulnerable environments like OWASP Juice Shop to practice web attacks.
